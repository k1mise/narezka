# Расширение «narez — вход в TikTok»

Нужно, чтобы кнопка «Войти» во вкладке TikTok (раздел «Аккаунты») сама входила в выбранный аккаунт в **том же браузере**, где открыта программа.

Установка (Chrome / Edge / Brave):
1. Открой `chrome://extensions`, включи «Режим разработчика».
2. «Загрузить распакованное расширение» → выбери эту папку `browser-extension`.
3. Обнови страницу narez (F5). В разделе «Аккаунты» → TikTok появится зелёная отметка «Расширение подключено».

Что делает кнопка «Войти»: стирает куки и локальные данные tiktok.com в этом браузере (выход из прежнего аккаунта), открывает страницу входа и вводит логин и пароль. Капчу и код подтверждения, если TikTok их потребует, вводишь сам.
